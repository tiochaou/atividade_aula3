# 🔍 Sobre o Projeto

Este projeto estuda os impactos dos **elementos gráficos** na usabilidade, navegabilidade e estética de páginas web. Comparamos plataformas de alta performance em **UI/UX** com sites que possuem problemas críticos de interface para mapear quais escolhas visuais geram engajamento e quais provocam a rejeição do usuário.

---

## 🎯 Objetivos da Pesquisa

🎨 **Cores & Contraste:** Mapear combinações funcionais e identificar erros de acessibilidade. <br>
✍️ **Tipografia:** Avaliar a legibilidade, o tamanho e o espaçamento adequado para leitura fluida. <br>
📐 **Hierarquia Visual:** Entender como a distribuição dos elementos guia o olhar do usuário. <br>
♿ **Acessibilidade Web:** Testar o cumprimento das diretrizes da WCAG em diferentes cenários. <br>
